# 犬の年齢計算アプリ 🐾

このアプリは、犬の年齢とサイズに基づいて人間年齢に換算するシンプルなツールです。愛犬の健康管理に役立ててください！🌟

## 機能

- **年齢の換算**  
  わんちゃんの年齢とサイズ（小型犬・中型犬・大型犬）を入力することで、人間年齢に換算したおおよその年齢を計算できます。

- **計算結果の表示**  
  換算された人間年齢と、子犬・成犬・シニア犬といったライフステージの目安が表示されます。

---

## 使用方法

1. **インストール**  
   Python 3.9以上が必要です。以下のコマンドを使用して必要なライブラリをインストールしてください。  

   ```bash
   pip install streamlit
   ```

2. **アプリの実行**  
   ターミナルで以下のコマンドを入力してアプリを起動します。  

   ```bash
   streamlit run app.py
   ```

3. **入力と結果の確認**  
   - アプリが起動したら、犬の年齢とサイズを入力し、「人間年齢に換算する」ボタンをクリックします。
   - 計算結果が表示されます。

---

## 計算式

このアプリでは、一般的に使われる換算方法を基に以下の計算を行っています：

- 1歳まで：年齢 × 15
- 1〜2歳：15 + (年齢 - 1) × 9
- 2歳以降：24 + (年齢 - 2) × サイズ別の加算年数（小型犬4／中型犬5／大型犬7）

---

## 注意事項

- 本アプリの計算結果は目安であり、すべての犬に当てはまるわけではありません。
- わんちゃんの個別の状況（犬種、健康状態など）に応じて調整してください。
- 詳細なアドバイスについては、獣医師に相談してください。
