# Shopifyへの設置

## これだけでOK

1. Shopify管理画面 → **オンラインストア → テーマ → カスタマイズ**
2. 画面の上のほうで、ページの種類を **「ブログ記事」** に切り替える
   （左上のプルダウンです。今どのページを編集しているかが出ている場所）
3. 左側の「＋ セクションを追加」→ **「カスタムLiquid」** を選ぶ
4. 出てきた四角の中に、`dog-age-calculator.liquid` の中身を**そのまま全部**貼り付ける
5. 右上の **「保存」**

これで、ブログの記事ページすべてに計算機が表示されます。設定やタグは不要です。貼ったら終わりです。

商品のおすすめ機能は使わなくても構いません。使わない場合は何もしなくて大丈夫です（商品の欄はただ出ないだけで、計算機は普通に動きます）。

---

## ここから先は、あとで気が向いたときに

すぐに必要なものではありません。上の手順だけで十分です。

### 特定の記事にだけ出したい

「全部の記事」ではなく「この記事だけ」に出したい場合は、貼り付けるときに次のように前後を挟みます（`年齢計算` の部分は好きな言葉にできます）。

```liquid
{% if article.tags contains '年齢計算' %}

  ←ここに dog-age-calculator.liquid の中身をぜんぶ貼る

{% endif %}
```

そのうえで、計算機を出したい記事の編集画面で、**タグに `年齢計算` を追加**して保存します。タグを付けた記事にだけ出ます。

### おすすめ商品を出したい

計算結果（子犬・成犬・シニア）に応じて、おすすめ商品を出すこともできます。使うコレクション（商品のまとまり）を3つ用意して、そのハンドル（URLの末尾）を控えます。

```
https://あなたのストア.myshopify.com/collections/puppy-food
                                                 ~~~~~~~~~~~ これがハンドル
```

貼り付けたコードの中ほどにある、次の部分を書き換えます。

```js
var DAC_CONFIG = {
  puppy:  { collection: "puppy",  title: "子犬の時期におすすめ" },
  adult:  { collection: "adult",  title: "成犬の時期におすすめ" },
  senior: { collection: "senior", title: "シニア期におすすめ" },
  limit: 3,                 // 出す商品の数
  currency: "JPY",          // 価格の通貨表示
  locale: "ja-JP"
};
```

`collection` の中身を、控えたハンドルに書き換えるだけです。

### 色を変えたい

コードのはじめのほうに、色の設定がまとまっています。

```css
.dac {
  --dac-accent: #9A6216;      /* 選択中・強調の色 */
  --dac-size-1: #6FAF8C;      /* 小型犬 */
  --dac-size-2: #358055;      /* 中型犬 */
  --dac-size-3: #14472F;      /* 大型犬 */
}
```

`--dac-accent` の右側の色コード（`#9A6216` など）を書き換えると、その色に変わります。それ以外の文字色・背景色はテーマに自動で合わせるので、触らなくて大丈夫です。

---

## うまくいかないとき

**貼り付けた説明文（「【入れ方】」など）がそのまま表示される**

貼った場所が「カスタムLiquid」になっていません。「カスタムHTML」や、記事本文の編集欄に貼っていないか確認してください。

**記事の本文の中に直接貼った**

それだと動きません。Shopifyは記事の本文を保存するときに、計算のしくみ（スクリプト）を取り除いてしまうためです。かならず「カスタムLiquid」のセクションに貼ってください（上の手順どおりです）。

---

## 動作確認したこと

- 子犬・成犬・シニアの切り替えで、計算結果とおすすめ商品が連動すること
- 売り切れ商品に「売り切れ」の表示が付くこと
- 明るいテーマ／暗いテーマの両方で読めること
- スマートフォンの画面幅でも横にはみ出さないこと
- コレクション未設定・商品0件・通信エラーでも、計算機自体は止まらず動くこと
