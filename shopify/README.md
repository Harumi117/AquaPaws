# Shopifyへの設置

`dog-age-calculator.liquid` は、Shopifyのページに貼り付けて使う犬の年齢計算ウィジェットです。計算結果のライフステージ（子犬・成犬・シニア）に合わせて、おすすめ商品が切り替わります。

アプリのインストールや、テーマファイルの編集は必要ありません。

---

## 1. コレクションを用意する

ライフステージごとに、おすすめ商品を入れたコレクションを3つ作ります。すでにあるコレクションを使ってもかまいません。

| ライフステージ | コレクションの例 |
|---|---|
| 子犬（1歳未満） | パピー用フード、しつけ用品など |
| 成犬（1〜7歳） | 成犬用フード、デンタルケアなど |
| シニア犬（7歳〜） | シニア用フード、関節ケア、ベッドなど |

あとで使うので、それぞれの **ハンドル** を控えておきます。ハンドルはコレクションのURLの末尾です。

```
https://あなたのストア.myshopify.com/collections/puppy-food
                                                 ~~~~~~~~~~~ これがハンドル
```

## 2. ページにコードを貼る

1. Shopify管理画面 → **オンラインストア** → **テーマ** → **カスタマイズ**
2. 上部のメニューから、設置したいページを選ぶ
3. **セクションを追加** → **カスタムLiquid**
4. `dog-age-calculator.liquid` の中身をすべてコピーして貼り付ける
5. **保存**

## 3. コレクションを設定する

貼り付けたコードの中ほどに、次の設定があります。手順1で控えたハンドルに書き換えてください。

```js
var DAC_CONFIG = {
  puppy:  { collection: "puppy",  title: "子犬の時期におすすめ" },
  adult:  { collection: "adult",  title: "成犬の時期におすすめ" },
  senior: { collection: "senior", title: "シニア期におすすめ" },
  limit: 3,                 // 出す商品の数
  currency: "JPY",          // 価格の通貨表示
  locale: "ja-JP"
};
```

- `collection` … コレクションのハンドル
- `title` … その商品欄の見出し
- `limit` … 表示する商品数（3〜4がおすすめ）

これで完成です。

## よくある調整

**商品を出したくない**

`collection` を空文字（`""`）にすると、そのステージでは商品欄が出ません。3つとも空にすれば、計算機だけのページになります。

**色を変えたい**

コードのはじめのほうに色の設定があります。`--dac-accent` がボタンや強調の色です。

```css
.dac {
  --dac-accent: #9A6216;      /* 選択中・強調 */
  --dac-size-1: #6FAF8C;      /* 小型犬 */
  --dac-size-2: #358055;      /* 中型犬 */
  --dac-size-3: #14472F;      /* 大型犬 */
}
```

文字色・背景・罫線はテーマから自動で受け継ぐので、明るいテーマでも暗いテーマでもそのまま使えます。犬のサイズを表す3色も、暗いテーマでは自動的に明るい側に切り替わります。

**同じページに2つ置きたい**

現在は1ページに1つの想定です（`id` を使っているため）。2つ必要な場合はご相談ください。

## 仕様と制限

- 商品はストア公開のJSONエンドポイント（`/collections/<ハンドル>/products.json`）から読み込みます。Shopifyの標準機能で、アプリや追加の権限は不要です。
- 価格はストアの既定通貨で表示されます。多通貨切り替えを使っている場合、お客様が選んだ通貨には追従しません。
- コレクションが見つからない、商品が0件、通信に失敗した場合は、**商品欄だけが消えて計算機はそのまま動きます**。ページが壊れることはありません。
- 一度読み込んだコレクションは記憶するので、ステージを行き来しても再通信しません。
- 計算結果は目安です。ページ下部に獣医師への相談を促す注意書きを入れてあります。

## 動作確認したこと

- 子犬・成犬・シニアの切り替えで、商品欄の見出し・商品・「すべて見る」リンクが連動すること
- 売り切れ商品に「売り切れ」が付くこと
- 明るいテーマ／暗いテーマの両方で読めること
- スマートフォン幅（390px）で横スクロールが出ないこと（商品は2列になります）
- コレクション不在・通信失敗・商品0件でも計算機が動き続けること
